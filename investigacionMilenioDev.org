* Descripción del Proyecto

Landing page para cliente Milenio. La página es informativa y además incluye un *configurador 3D interactivo* donde los usuarios pueden:

1. Seleccionar un espacio (modelo a escala hecho por arquitecto)
2. Aplicar materiales/texturas del catálogo del cliente mediante drag & drop
3. Ver el costo calculado automáticamente (m² × precio del material)
4. Exportar la cotización enviando una foto del modelo y el desglose de precios por WhatsApp

* Evaluación de Tecnologías 3D

** Unity WebGL — Descartado

- *Problema principal:* Bundle inicial de 20–50 MB antes de renderizar nada
- Impacto negativo en conversión de la landing page
- Comunicación Unity ↔ web mediante puente JavaScript, difícil de mantener
- Actualizaciones requieren rebuild y redeploy independiente del resto del sitio

** Babylon.js — Opción válida pero no óptima

- Tiene ejemplos reales de room planners (3dhouseplanner.com, room-editor en GitHub)
- Excelente rendimiento para escenas complejas
- *Desventaja:* Integración con React no es nativa; el configurador y la landing quedan desacoplados

** React Three Fiber (R3F) — *RECOMENDADO*

- Three.js escrito como componentes React nativos
- Ecosistema activo con casos de uso idénticos al proyecto (configuradores con texturas)
- Existe curso específico de configuradores con R3F: https://threejsresources.com/tool/react-three-fiber-configurator-course
- Paquetes clave disponibles: =@react-three/drei=, =@react-three/rapier=

* Flujo del Configurador

1. Usuario entra al configurador 3D (sección dentro de la landing)
2. Carga el modelo a escala del espacio (archivo =.glb=)
3. Panel lateral muestra el catálogo de materiales del cliente (pisos, paredes, revestimientos)
4. Drag & drop del material sobre la superficie → textura aplicada en tiempo real
5. Sistema calcula: =m² de superficie × precio del material=
6. Botón "Cotizar" → captura screenshot del canvas 3D → abre WhatsApp con imagen y desglose de precios
